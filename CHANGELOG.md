# Luma 0.4.12

**Light, beautifully controlled.**

A lightweight macOS menu bar app for BenQ iScreenBar.

- Refined controls and settings, with Liquid Glass on supported macOS versions.
- Customizable scenes with immediate saving.
- A monochrome menu bar symbol and no Dock icon.
- Customizable brightness shortcuts with continuous adjustment while held.
- Keyboard/mouse idle shutoff from 5 seconds to 30 minutes, alongside hardware presence detection.
- App, camera, sleep/wake, and Night Shift automation.

## Installation

Move Luma.app to Applications. DMG and ZIP contain the same Universal app (Apple Silicon + Intel), requiring macOS 14 or later. The app interface is Simplified Chinese.

Ad-hoc signed; not Apple-notarized. Intel and older macOS releases have not been tested on physical hardware. See the README for installation instructions and compatibility limits. SHA256 checksums are attached.
